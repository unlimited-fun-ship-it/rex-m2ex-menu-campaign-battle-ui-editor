A vibe-coded attempt at an editor for the REX & M2EX menu, campaign, and battle ui. 

I've made a version of this program which is just for editing the in-campaign ui. 
It can kind some what edit the campaign ui I think. I'm not sure if it actually edits things or saves them for the actual user to experience the difference in-game yet.
Grab the improved4 folder and run improved4/main.py


It can't really edit it yet (I think) but it's a start to it. 
Look in the campaign folder and then choose any one of the folders "functional style", "imperative style", or "oop style" 
and then run the main.py file inside the folder that you choose.
